# Scop

Acest registru înregistrează informațiile de guvernanță pentru toate seturile de date folosite de sistemele de Inteligență Artificială din {{COMPANY_NAME}}.

Oferă dovada obiectivă că datele folosite de sistemele AI sunt identificate, clasificate, revizuite și guvernate conform Regulamentului (UE) 2024/1689 (EU AI Act) și Regulamentului (UE) 2016/679 (GDPR).

---

# Niveluri de Clasificare a Datelor

Se folosesc următoarele clasificări:

- Public
- Intern
- Confidențial
- Restricționat

---

# Criterii de Calitate a Datelor

Fiecare set de date se evaluează periodic pentru:

- Exactitate
- Completitudine
- Consecvență
- Integritate
- Actualitate
- Relevanță

---

# Cerințe de Revizuire

Registrul se actualizează ori de câte ori:

- este introdus un sistem AI nou;
- este adăugată o sursă de date nouă;
- se schimbă clasificarea datelor;
- sunt identificate probleme de calitate a datelor;
- se modifică cerințele de reglementare.
